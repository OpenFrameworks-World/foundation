# OpenFrameworks Foundation v0.1.0 — Release Candidate

## Status

Release Candidate

This release candidate packages the first coherent OpenFrameworks Foundation model.

It defines the constitutional principles, ontology, governance kernel, runtime kernel, graph schema, language, compiler, execution engine, and reference implementation boundary required to build the OpenFrameworks Platform.

---

## Constitutional Principles

```text
Everything is a framework.
Everything must be composable without losing capability.
```

These two principles govern the entire foundation.
