# OpenFrameworks World Principle

The world is represented in frameworks.

OpenFrameworks exists to make those frameworks discoverable, governable, trustworthy, publishable, comparable, reusable, and useful.

## Meaning

A framework is a reusable structure for representing how something is understood, organized, governed, evaluated, operated, or improved.

The world contains many domains, institutions, systems, methods, practices, policies, controls, architectures, standards, protocols, decisions, and operating models.

OpenFrameworks represents them as frameworks so they can be described, connected, evaluated, published, trusted, and reused.

## Separation

```text
World
  -> represented in frameworks

Foundation
  -> defines the contract for representing frameworks

Platform
  -> operationalizes framework representation, publishing, governance, discovery, trust, and reuse
```

## Core Line

```text
The world is represented in frameworks.
```
